# 🛡️ SafeTrail – Smart Tourist Safety Monitoring System

A browser-based Smart Tourist Safety Monitoring and Incident Response prototype designed to improve tourist safety through location awareness, geofencing, emergency reporting and safety monitoring.

## 🎯 Problem Statement
Tourists may face emergencies in unfamiliar locations, including accidents, theft and entry into unsafe areas. SafeTrail demonstrates a centralized interface for monitoring safety conditions and reporting incidents.

## ✨ Key Features
- 📍 Browser-based GPS location access
- 🗺️ Safe, caution and restricted geofence zones
- 🚨 SOS emergency alert demonstration
- 🛡️ Rule-based safety risk assessment
- 📋 Incident reporting and management
- 👮 Simulated safety monitoring dashboard
- 📊 Incident history and CSV export
- 🏥 Nearby police stations, hospitals and pharmacies search

## 🧰 Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Geolocation API
- LocalStorage
- Google Maps links

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in Chrome, Edge or Firefox.
4. Allow location permission when prompted.

## ⚠️ Project Limitations
This is a front-end prototype. Location zones are illustrative, incident data is stored locally, and SOS alerts do not automatically contact emergency services. Risk assessment is rule-based, not a trained machine learning model.

## 🔮 Future Enhancements
- Backend API and cloud database
- Secure authentication and authorization
- Official GIS-based geofencing
- Verified SMS and push notifications
- Validated incident datasets and ML-based risk prediction
- Integration with authorized emergency services
